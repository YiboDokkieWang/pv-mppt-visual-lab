# PV MPPT Visual Lab

An interactive, browser-based visualization platform for comparing photovoltaic maximum power point tracking algorithms on measured I–U and P–U characteristic curves.

The site runs entirely in the browser and includes conventional MPPT methods, fuzzy logic control, metaheuristic optimization algorithms, and demonstration-oriented machine-learning methods.

## Website

After GitHub Pages is enabled, the public site will be available at the repository's Pages URL.

## Notes

- This repository contains the deployable static website.
- The simulation is intended for algorithm visualization and comparison.
- The machine-learning demonstrations use the supplied operating-condition data for both training and testing and are not representative of performance on independent datasets.
